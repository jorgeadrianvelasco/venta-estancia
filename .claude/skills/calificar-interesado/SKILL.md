# Calificar un interesado

**Los criterios de abajo son un primer borrador (15/10/2026) y Jorge todavía no los aprobó.** Cuando los
corrija, se reescribe esta Skill y se anota en `decisiones.md`.

## 1. Leer antes
- `negocio.md`: precio, forma de pago, qué se vende.
- `respuestas.md`: respuestas aprobadas.
- `interesados.md`: si la persona ya consultó antes.

## 2. Qué mirar en la consulta

| Señal | Suma | Resta |
|---|---|---|
| Pregunta concreta (hectáreas, agua, papeles, acceso) | ✔ | |
| Ya tiene campo o ganado en la zona | ✔ | |
| Habla de plazos o de forma de pago | ✔ | |
| Pide visitar | ✔ | |
| Decide él o dice quién decide | ✔ | |
| Solo "precio?" sin nada más | | (no descarta: pedir un dato más. Si se va, es curioso, y a Jorge no le molesta) |
| Ofrece permuta o pago que Jorge no acepta (`negocio.md`) | | ✔ |
| No responde a dos mensajes seguidos | | ✔ |

**No se descarta a nadie por un solo mensaje.** Un "precio?" puede ser un comprador serio que escribe corto.

## 3. Calificación y próximo paso

| Calificación | Cuándo | Próximo paso |
|---|---|---|
| **serio** | Pregunta concreta + capacidad o plazo visibles, o pide visita | Avisar a Jorge el mismo día; proponer visita o llamada |
| **a confirmar** | Interés real pero falta un dato clave | Una pregunta para confirmarlo |
| **curioso** | Sin datos ni intención visible después de responderle | Respuesta aprobada y seguimiento en una semana |
| **descartado** | Lo dice él, o no cumple una condición que Jorge fijó | Cerrar con cortesía |

## 4. Responder
- Usar solo respuestas de `respuestas.md`. Si la pregunta no tiene respuesta aprobada, **no se inventa**:
  se propone un borrador a Jorge y se espera su aprobación.
- **El precio no se da por escrito** (`decisiones.md`), y **nunca** se dice el mínimo que Jorge aceptaría.
- No se persigue a quien solo preguntó el precio: lo que busca Jorge es interés serio, no volumen.

## 5. Dejarlo escrito
- Fila nueva (o actualizada) en `interesados.md`.
- Si la pregunta es nueva, agregarla a `respuestas.md` como "pendiente".
- Si se aprendió algo sobre quién compra, agregarlo a `comprador.md` con fecha.
