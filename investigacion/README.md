# Investigación

Cada investigación es un archivo con nombre descriptivo (minúsculas y guiones), con:
- hallazgos en tablas, marcados `[DATO — URL]` o `[ESTIMACIÓN]`;
- `## Qué quedó sin verificar`, con el motivo;
- `## Fuentes`, con todas las URLs.

Un hallazgo que no queda en un archivo se pierde al cerrar la sesión.
